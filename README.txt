HOW TO RUN
1. Install .NET 8 SDK and PostgreSQL (remember the postgres password).
2. Open appsettings.json and replace  your_password  with your PostgreSQL password.
3. Open a terminal in this folder and run:   dotnet run
   (or open SmartPharmacySystem.csproj in Visual Studio 2022 and press F5)
4. Browser opens at http://localhost:5080 - database and sample data are created automatically.
